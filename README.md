📌 Overview

This project demonstrates a complete end-to-end Data Analytics Workflow.
It covers everything from loading raw data to generating insights and presenting them professionally.

The project includes:

Data loading in Python

Exploratory Data Analysis (EDA)

Data cleaning and preprocessing

SQL analysis using PostgreSQL / MySQL / SQL Server

Building a Power BI dashboard

Creating a business report

Designing a presentation using Gamma

This project showcases strong analytical thinking, SQL expertise, visualization skills, and business storytelling.

📈 Results & Insights

Key insights discovered in the project (examples):

Repeat customers contribute higher total revenue

Express shipping has higher purchase amounts

Certain categories dominate overall sales

Top 3 items per category drive majority of orders

Customer loyalty strongly correlates with purchase value

These insights help improve product strategy, customer retention, and marketing decisions.

▶️ How to Run This Project
1. Clone the Repository
git clone https://github.com/nasiralam/customer-behavior-analysis.git

2. Install Dependencies
pip install -r requirements.txt

3. Run Python Notebook

Open Jupyter Notebook:

jupyter notebook


Run the file:

EDA_and_cleaning.ipynb

4. Setup Database Connection

Update database credentials in the script:

engine = create_engine("postgresql+psycopg2://username:password@localhost:5432/database")

5. Execute SQL Queries

Use the SQL scripts provided in the /sql folder.

6. Open Power BI Dashboard

Open the .pbix file in Power BI Desktop.

7. View Report & Presentation

Check the /report and /presentation folders.
